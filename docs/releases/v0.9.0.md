## Shogun Emulator v0.9.0

最初の公開版です。 / This is the first public release.

### English

Shogun Emulator is an NES (Famicom) emulator for macOS, Windows, and Linux, with development tools and an interface for AI agents.

- **Emulation**: NTSC, PAL, and Dendy. Mappers NROM (0), MMC1 (1), UxROM (2), CNROM (3), MMC3 (4), AxROM (7), and GxROM (66).
- **Play**: save states with slots, rewind, fast-forward, slow motion, frame advance, input movie recording and playback, and screenshots.
- **Debugging**: CPU debugger with breakpoints and stepping by cycle, instruction, scanline, or frame; memory viewer and editor; pattern table, nametable, sprite, palette, and APU viewers; CPU trace log; ca65/ld65 `.dbg` symbols.
- **AI agents**: an MCP server (`shogun mcp`) and a JSON-RPC server (`shogun serve`) for controlling, observing, and debugging the emulator, plus a scenario runner (`shogun run`).
- **Installers**: `.dmg` for macOS, `.msi` for Windows, and `.deb`, `.rpm`, and AppImage for Linux.

The user interface is in Japanese.

### 日本語

将軍エミュレータは、macOS・Windows・Linux で動く NES（ファミリーコンピュータ）のエミュレータです。開発用の道具と、AI エージェントから使うための窓口を備えています。

- **デバッグ**: ブレークポイントとサイクル・命令・スキャンライン・フレーム単位のステップ実行ができる CPU デバッガ、メモリビューアとエディタ、パターンテーブル・ネームテーブル・スプライト・パレット・APU のビューア、CPU トレースログ、ca65/ld65 の `.dbg` のシンボル
- **AI エージェント**: エミュレータを操作・観測・デバッグする MCP サーバ（`shogun mcp`）と JSON-RPC サーバ（`shogun serve`）、Scenario の実行（`shogun run`）
- **インストーラ**: macOS は `.dmg`、Windows は `.msi`、Linux は `.deb`・`.rpm`・AppImage
